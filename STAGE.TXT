# STAGE.TXT - which of this pack's INFs may be staged, on which Windows
#
# Read by the xHCI98 installer (roadmap-usb4 task 43.48) when the user ticks
# the non-free pack's optional "let Windows use these automatically when a
# device is plugged in" box. The installer copies the whole pack whether or
# not the box is ticked; this file says only what the box may stage (place
# where Windows finds it at the first plug of the device: the INF folder on
# 98 SE and ME, SetupCopyOEMInf on 2000 and later). Nothing here installs a
# driver, and no vendor file is changed by this file.
#
# Format. Plain ASCII text, CRLF or LF line ends. A line starting with '#'
# and a blank line are comments. Every other line is four fields separated
# by '|', each trimmed of spaces:
#
#   ACTION | SYSTEMS | INF | NOTE
#
#   ACTION   STAGE  the box may stage this INF on the systems named.
#            COPY   copy-only: never staged by the box, on any system (the
#                   files are still copied with the rest of the pack).
#   SYSTEMS  one or more of these tokens, separated by spaces:
#            W98SE WME W2K WXP WXP64 WVISTA WVISTA64 W7 W7X64
#            (WXP64 is Windows XP Professional x64 Edition; WVISTA64 and
#            W7X64 the 64-bit editions). On a COPY line, the systems the
#            folder is for, for information only.
#   INF      the INF's path from the pack's top, '/' separated, exactly as
#            in SHA256.TXT (case as the vendor shipped it; may hold spaces).
#   NOTE     free text, why; may be empty.
#
# Rules the file keeps (and a reader may check):
#   - Every INF under non-free/ is on exactly one line.
#   - On any one system, no two STAGE lines match the same hardware ID (as
#     their [Models] sections are read for that system). Where two INFs in
#     the pack would match the same ID, one is chosen here, by name, and the
#     other is restricted to other systems or is COPY.
#   - nusb33/ is not listed and never staged by the non-free box: xHCI98's
#     own NUSB storage row owns those files.
#   - A driver whose maker installs it only with a setup program is COPY.
#     Today every driver in the pack has its own INF; the setup programs
#     beside some of them (Realtek's setup.exe, WCH's SETUP.EXE and
#     DRVSETUP64.exe, FTDI's uninstallers, Morii's x360csai.exe,
#     x360wcsai.exe and x360csa.exe) are copied, never run.
#   - SYSTEMS follows README.md's table of which folder serves which
#     Windows, not every system an INF's own decorations would accept.
#
# The drivers here are carried as their makers released them and have not
# been tested by this project. The choices below were made by reading the
# INFs (2026-10-22); those marked "owner to confirm" await the owner.
